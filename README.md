# Mein To-do-Dashboard

https://nick-1205.github.io/dashboard/#/

## Über das Projekt

Im Rahmen meiner Umschulung zum Fachinformatiker für Anwendungsentwicklung
habe ich dieses To-do-Dashboard entwickelt.

Mir war dabei wichtig, eine übersichtliche Benutzeroberfläche zu gestalten,
die einfach zu bedienen ist.

# Was kann die Anwendung?

- Neue Aufgaben erstellen und nicht mehr benötigte Aufgaben löschen.
- Aufgaben in einer Kartenansicht oder Tabellenansicht anzeigen.
- Zu jeder Aufgabe eine kurze Beschreibung hinzufügen.
- Erledigte Aufgaben markieren.
- Den aktuellen Fortschritt im Dashboard sehen.

# Einblick in das Projekt

Die Anwendung besitzt ein dunkles Design mit einer türkisfarbenen Kopfzeile.

In der Kartenansicht werden die Aufgaben einzeln dargestellt.
In der Tabellenansicht erhält man einen schnellen Überblick über alle Aufgaben.

Erledigte Aufgaben werden farblich hervorgehoben, damit man auf einen Blick
erkennen kann, was bereits geschafft wurde.
